🛒 Marketplace IPFS

O registry de plugins fica no IPFS via Pinata — distribuiçêo descentralizada, imutável, com CID versionado em discovery.ts. Resultado: ninguém pode silenciosamente trocar conteúdo de um plugin já publicado.

🔐Por que IPFS

  • •Conteúdo identificado por hash (CID) — verificável
  • •Distribuído — sem ponto único de falha
  • •Histórico íntegro — versêo anterior sempre acessível
  • •Gateway HTTPS via Pinata para acesso simples

📍Onde mora o registry

v3/@claude-flow/cli/src/plugins/store/discovery.ts
LIVE_REGISTRY_CID = "QmXbfEAaR7D2Ujm4..."
gateway: https://gateway.pinata.cloud/ipfs/{CID}

📥 Install / enable / disable

Instalar um plugin é download do CID + verificaçêo + setup. Você pode habilitar/desabilitar sem reinstalar — útil para alternar features sem custo.

⚙️Comandos essenciais

# Listar disponíveis
npx claude-flow@v3alpha plugins list

# Instalar
npx claude-flow@v3alpha plugins install @claude-flow/rag-memory

# Habilitar/desabilitar
npx claude-flow@v3alpha plugins enable @claude-flow/rag-memory
npx claude-flow@v3alpha plugins disable @claude-flow/rag-memory

# Remover
npx claude-flow@v3alpha plugins uninstall @claude-flow/rag-memory

💡Dica prática

Plugins instalados ficam em ~/.claude-flow/plugins/. Se precisar de patch local, edite ali — mas saiba que update sobrescreve. Para mudanças permanentes, fork e use install local.

🔧 Plugin management

Versêo errada, conflito de deps, plugin que nêo carrega — todos enfrentam. Esses sêo os passos de troubleshooting que resolvem 90% dos casos.

✓ Boas práticas

  • ✓Pin versões em produçêo (nêo use latest)
  • ✓Update em staging primeiro
  • ✓Teste com doctor após cada install
  • ✓Mantenha changelog de plugins ativos

✗ Evite

  • ✗Instalar tudo "por garantia"
  • ✗Misturar versões alpha + stable
  • ✗Atualizar prod sem rollback plan
  • ✗Editar plugin instalado direto

🔬Troubleshooting básico

  1. npx claude-flow@v3alpha doctor --fix — diagnostica e tenta corrigir
  2. plugins list --enabled — vê o que está ativo
  3. plugins disable X — isolar plugin suspeito
  4. Reinstale com --force se cache corrompeu
