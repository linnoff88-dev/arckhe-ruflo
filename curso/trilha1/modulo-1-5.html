🚀 Init

init é seu ponto de partida. Cria estrutura, instala hooks padrêo, configura skills e conecta MCP. Use o wizard interativo na primeira vez — depois você só precisa de presets.

⚡Variantes

Wizard interativo (recomendado):

npx claude-flow@v3alpha init --wizard

Preset rápido:

npx claude-flow@v3alpha init --preset coding

Com skills e hooks:

npx claude-flow@v3alpha init --skills --hooks

💡Dica

No wizard, aceite os defaults — eles refletem boas práticas anti-drift (hierarchical, 8 agentes, raft). Você sempre pode editar claude-flow.config.json depois.

2

👤 Agent

agent gerencia o ciclo de vida de cada agente: spawn, list, status, stop, metrics, pool, health, logs. 8 subcomandos cobrem tudo que você precisa para inspecionar e operar.

📋Os 8 subcomandos

  • spawn — cria nova instância de agente
  • list — lista agentes ativos
  • status — estado atual de um agente
  • stop — finaliza graciosamente
  • metrics — tempo, tokens, sucesso
  • pool — gerencia pool de agentes reusáveis
  • health — diagnóstico de saúde
  • logs — output recente do agente
1

Spawn

npx claude-flow@v3alpha agent spawn -t coder --name my-coder
2

List + Status

npx claude-flow@v3alpha agent list
npx claude-flow@v3alpha agent status my-coder
3

Logs + Metrics

npx claude-flow@v3alpha agent logs my-coder
npx claude-flow@v3alpha agent metrics
3

🐝 Swarm

swarm orquestra times de agentes. init com topologia, status para inspecionar, monitor em tempo real. É o comando que transforma agentes individuais em time coordenado.

🐝Comandos chave

Inicializar swarm:

npx claude-flow@v3alpha swarm init --topology hierarchical --max-agents 8

Status do swarm:

npx claude-flow@v3alpha swarm status

Monitor em tempo real:

npx claude-flow@v3alpha swarm monitor --watch

💡Dica

Combine --strategy specialized com --consensus raft para cenários anti-drift. Esse é o setup recomendado para coding em produçêo.

4

💾 Memory

memory é o comando que toca AgentDB. 11 subcomandos cobrem store/search/retrieve/list/import/export. A busca é HNSW por baixo: 150x-12.500x mais rápida que linear.

💾Operações comuns

Armazenar:

npx claude-flow@v3alpha memory store --namespace patterns --key "auth-flow" --value "..."

Buscar (semântica):

npx claude-flow@v3alpha memory search -q "authentication patterns"

Recuperar:

npx claude-flow@v3alpha memory retrieve --namespace patterns --key "auth-flow"

✓ Boas práticas

  • ✓Namespace por feature/projeto
  • ✓Keys descritivas em kebab-case
  • ✓Search semântico antes de assumir que algo nêo existe
  • ✓Export periódico para backup

✗ Anti-padrões

  • ✗Tudo em "default" ou "global"
  • ✗Keys com timestamps no meio
  • ✗Armazenar segredos sem cifrar
  • ✗Esquecer de limpar namespaces obsoletos
5

🩺 Doctor

doctor é seu primeiro recurso quando algo nêo funciona. Faz health check completo: Node 20+, npm 9+, git, config válida, daemon ativo, memory DB OK, API keys, MCP servers, espaço em disco, TypeScript instalado.

🩺Modos

Diagnóstico passivo:

npx claude-flow@v3alpha doctor

Auto-correçêo:

npx claude-flow@v3alpha doctor --fix

💡Dica

Rode doctor antes de abrir issue. 80% dos problemas sêo detectados (e corrigidos com --fix) automaticamente.

⚠️Quando algo dá errado

Se doctor --fix nêo resolve: 1) verifique .env com ANTHROPIC_API_KEY; 2) confira se daemon start retorna OK; 3) limpe ~/.claude-flow/cache e reinicie.

6

⚙️ Daemon

daemon roda 12 background workers: ultralearn, optimize, consolidate, predict, audit, map, preload, deepdive, document, refactor, benchmark, testgaps. Sem daemon, hooks ainda funcionam, mas você perde aprendizado contínuo.

⚙️Lifecycle

Iniciar:

npx claude-flow@v3alpha daemon start

Status:

npx claude-flow@v3alpha daemon status

Disparar worker manualmente:

npx claude-flow@v3alpha daemon trigger --worker audit
1

Start

Sobe processo de fundo, registra workers, abre socket de IPC.

2

Trigger

Hooks acionam workers automaticamente — você raramente precisa disparar manualmente.

3

Stop

Encerra graciosamente, drena filas, persiste estado antes de sair.
